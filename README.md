# 리리와 함께하는 인천 세계시민 탐험 (웹 버전)

인천형 세계시민교육(읽걷쓰 4P) × 읽걷쓰 AI × 금융교육 비주얼 노벨 · 초등학생 1인칭 · 약 10~12분

**빌드가 필요 없는 웹 게임**이에요. GitHub에 파일을 올리기만 하면 링크로 바로 실행돼요. (Ren'Py 설치 필요 없음)

## GitHub에 올려서 링크 만들기

1. github.com → **+ → New repository** → 이름 예: `incheon-global-citizen` → **Public** → **Create repository**
2. **uploading an existing file** 클릭
3. 압축을 푼 뒤 나오는 **파일과 폴더 전부**를 끌어다 놓기 → **Commit changes**
   - 올린 뒤 저장소 첫 화면에 `index.html`, `style.css`, `js`, `assets`, `README.md` 가 **바로 보여야** 해요.
   - 폴더 하나만 보이고 그 안에 파일이 있으면 README만 보이는 문제가 생겨요.
4. **Settings → Pages → Build and deployment → Source: `Deploy from a branch`** → Branch: **main**, **/(root)** → **Save**
   - ⚠️ `GitHub Actions` 로 되어 있으면 게임이 뜨지 않아요. 꼭 `Deploy from a branch` 로!
5. 1~2분 뒤 Pages 화면 맨 위 **“Your site is live at …”** 주소가 게임 링크예요 → QR코드로 만들어 부스에 붙이세요.

> 게임 링크는 `github.com/…`이 아니라 `아이디.github.io/저장소이름/` 이에요.

- 장소를 옮길 때 **버스가 인천 지도 위를 달리는 이동 애니메이션**
- 정답 시 색종이·별 터지기, 오답 시 화면 흔들림·연기, 동전 튀기기 효과
- 캐릭터 등장·말하기·감정 이모티콘(❗❓💧✨) 애니메이션, 배경 천천히 움직이기, 장소별 분위기 효과(물방울·꽃잎·낙엽·별)
- **🔥 연속 통과 콤보**와 **🏅 업적 배지 13개** (예산왕, 팩트체커, 물범 지킴이, AI 이긴 사람 …) — 점수에는 영향 없음
- 사목에서 리리가 말을 걸어요(“계산 중… 삐빅!”, “앗, 거긴 내가 막아야지!”)

## 내용·난이도 고치기

| 고칠 것 | 파일 |
|---|---|
| 선택지 문장, 점수, 해설, 제한시간, 통과 기준, 배지 | `js/data.js` |
| 대사와 장면 순서 | `js/story.js` |
| 미니게임 난이도 (함정 개수, 슈팅 시간·목표, 사목 수 제한·AI 실수 확률, 복권 확률) | `js/games.js` 맨 위 숫자 |
| 글자 크기·색 | `style.css` |

GitHub에서 파일을 열고 연필(✏️)로 고친 뒤 **Commit changes** → 1~2분 뒤 링크에 반영돼요.

## 운영 팁
- 순위·통과율 기록은 게임을 한 **그 기기(브라우저)**에 저장돼요. 엔딩 2쪽 **순위 초기화(선생님용)** 로 지울 수 있어요.
- 소리는 첫 터치 뒤부터 나와요(브라우저 규칙). 오른쪽 위 🔊 로 끄고 켤 수 있어요.
- 조작: 클릭/터치 · Space/Enter = 다음 · 숫자 1~4 = 선택지
- 휴대폰은 가로로 돌려서 해요.
